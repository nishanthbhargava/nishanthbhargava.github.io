AI-Powered Learning Introduction (Case Study)

Project Overview

This project demonstrates the integration of AI tools within the instructional design workflow. The objective was to create an engaging learning introduction using an AI avatar while maintaining instructional clarity and learner focus.

My Role

  • Conceptualized the learning introduction
  • Structured the instructional flow
  • Scripted the narration using ChatGPT as a drafting assistant
  • Refined and humanized the script for clarity and tone
  • Generated the AI avatar video using HeyGen
  • Edited and enhanced the final output in Adobe Premiere Pro

Instructional Strategy

The introduction was designed to:

  • Establish learning context clearly
  • Set expectations for the module
  • Create learner engagement within the first 60 seconds
  • Use conversational tone while maintaining professional credibility
